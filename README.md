# CIND860 – Advanced Data Analytics Project

This repository contains the full analytical workflow for my CIND860 project at Toronto Metropolitan University.  
The goal of the project is to apply advanced data analytics techniques to extract insights, build predictive models, and evaluate their performance using industry‑standard methodologies.

## Project Objectives
- Understand the structure and characteristics of the Acute Lymphoblatic Leukemia clinical dataset  
- Perform thorough exploratory data analysis  
- Build and compare multiple machine learning models  
- Evaluate model performance using robust metrics  
- Communicate findings clearly and professionally  

## Workflow Summary
1. **Data Cleaning** – Missing values, duplicates, outliers  
2. **Feature Engineering** – Encoding, scaling, transformations  
3. **EDA** – Visual and statistical exploration  
4. **Modeling** – Decision Tree, Random Forest, Gradient Boosting, Logistic Regression  
5. **Evaluation** – Accuracy, F1, ROC‑AUC, confusion matrices  
6. **Interpretation** – Feature importance and insights  

## Repository Layout
- `notebooks/` – Interactive Colab notebooks  
- `src/` – Modular Python scripts  
- `results/` – Charts, metrics, and exported outputs  
- `data/` – Dataset placeholder  

## Technologies Used
Python, pandas, numpy, scikit‑learn, matplotlib, seaborn, Google Colab.

## How to Use
Clone the repository or open the notebook directly in Google Colab.  
Run the notebook sequentially to reproduce all results.
